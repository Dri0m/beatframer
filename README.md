# BeatFramer

A Beat Saber (`1.44.1`) performance optimization mod and experimental ultra-lightweight renderer. Originally built to get Beat Saber running at a locked 144 Hz on the **Steam Frame** (Snapdragon 8 Gen 3 / Adreno 750, running PC Beat Saber patched with native Windows ARM64 Unity/Mono binaries via [bs-arm64](https://github.com/DaVarga/bs-manager/blob/bs-arm64/docs/steam-frame.md) under ARM64 Proton + DXVK + Mesa Turnip), and works as a normal BSIPA mod on **x86_64 Windows/Linux PCVR** too.

## Does it work on regular x86_64 PC Beat Saber?

**Yes.** There is no ARM64-specific, SteamOS-specific, or native C/C++ code in `BeatFramer.dll`. Even though `bs-arm64` swaps Beat Saber's native engine binaries (`Beat Saber.exe`, `UnityPlayer.dll`, Mono, etc.) for native Windows ARM64 builds, the managed C# game assemblies (`Main.dll`, `Rendering.dll`, `HMRendering.dll`, etc.) are the same architecture-independent IL as standard x86_64 PC Beat Saber `1.44.1`. `BeatFramer.dll` is a pure `AnyCPU` `.NET Framework 4.7.2` BSIPA plugin with no native DLLs.

- **Windows PCVR (x86_64, D3D11):** drop `Plugins/BeatFramer.dll` into your Beat Saber folder. Ignore `dxvk.conf`.
- **Steam Frame / Linux / SteamOS (Proton + DXVK):** drop `Plugins/BeatFramer.dll` into your Beat Saber folder, and optionally copy `dxvk.conf` next to `Beat Saber.exe`.

The optimizations were driven by mobile tile-based GPU bottlenecks (where offscreen HDR RenderTargets, floor reflection re-renders, and screen-grab blits are especially expensive), but cutting those passes reduces GPU and CPU load on desktop GPUs and laptops as well.

## Quick install

Requires PC Beat Saber **`1.44.1`** with:
- `BSIPA` (`^4.3.0`)
- `SiraUtil` (`^3.1.0`)
- `BeatSaberMarkupLanguage` / BSML (`^1.11.0`)

1. Grab `BeatFramer-v0.1.0.zip` from [Releases](https://github.com/Dri0m/beatframer/releases) (or build it yourself below).
2. Copy `Plugins/BeatFramer.dll` into your Beat Saber `Plugins/` folder.
3. *(Optional, Proton / Steam Frame / Linux only)* Copy `dxvk.conf` into the Beat Saber root folder next to `Beat Saber.exe`.
4. Launch Beat Saber and open **Mod Settings → BeatFramer** in VR.

**Uninstall:** delete `Plugins/BeatFramer.dll` (and optionally `dxvk.conf` and `UserData/BeatFramer.json`).

## What it does

Everything is configurable live in VR under **Mod Settings → BeatFramer** (saved to `UserData/BeatFramer.json`).

### 1. `Optimized` mode (default — tested)
Keeps Beat Saber's stock look and environments, while stripping the heaviest GPU/CPU passes via guarded Harmony patches and Unity/XR settings:

- **No desktop mirror blit:** `XRSettings.gameViewRenderMode = None` (stops blitting VR eyes to the desktop window every frame).
- **No floor reflection re-render:** patches `MirrorRendererSO.RenderMirrorTexture` to return `null`, triggering Beat Saber's native no-mirror dark floor material instead of rendering the entire scene a second time.
- **No offscreen HDR bloom post-process:** disables `MainEffectController._imageEffectController` while keeping `mainEffect.PreRender()` intact (so dot-block glow and note brightness stay normal).
- **Half-res `BloomPrePass`:** halves `BloomPrePassEffectSO` width and height (4× fewer pixels; optional full disable toggle also available).
- **No wall/screen grab passes:** skips `CommandBufferGOCore.OnWillRenderObject`.
- **No burn marks, note debris, or shockwaves:** skips `SaberBurnMarkArea`, `SaberBurnMarkSparkles`, `NoteDebrisSpawner`, `ShockwaveEffect` (cut particles remain ON by default, toggleable).
- **Lighter saber trails:** caps `SaberTrail` granularity (`<= 24`) and sampling frequency (`<= 60`).
- **Mid-song GC pause suppression:** disables Unity's incremental/stop-the-world GC during `GameCore` (`GarbageCollector.GCMode = Disabled`) and re-enables + collects Gen0 cleanly when returning to the menu.
- **Unity quality & camera tuning:** disables shadows, pixel lights, soft particles, realtime reflection probes, anisotropic filtering, `Physics.autoSyncTransforms` in gameplay, `depthTextureMode`, and sets `farClipPlane = 220` and `maxQueuedFrames = 1`.
- **Optional `dxvk.conf` (Proton/Linux/Steam Frame):** sets `d3d11.maxFrameLatency = 1`, `d3d11.relaxedBarriers = True`, `d3d11.constantBufferRangeCheck = False`, `d3d11.invariantPosition = False`, and `dxvk.enableGraphicsPipelineLibrary = True`.

### 2. `LiteRenderer` mode (experimental / WIP)
An experiment in replacing Beat Saber's gameplay rendering with a **3-draw-call batched renderer** (`LiteRendererController.cs`) while keeping 100% of Unity's `GameObject`s, hitboxes, scoring, audio, HUD/BSML UI, and mods untouched.

- Disables stock non-UI `MeshRenderer`s during gameplay (`GameCore`) and batches notes (cubes, arrows, dots, chain links), bombs, walls, sabers, trails, and live `LightWithIdManager`-driven neon environment rails/rings/lasers into 3 dynamic meshes (opaque, translucent, additive) using Unity's built-in `Hidden/Internal-Colored` shader.
- **Status:** the 3-draw-call batched rewrite compiles cleanly and has not yet been fully playtested in VR. Expect rough edges; use `Optimized` for normal play.

### 3. `Stock` mode & optional telemetry
- Switch **Renderer Mode** to `Stock` in Mod Settings for quick A/B comparison without uninstalling.
- **Log Frame-Time Benchmarks** is **OFF by default** (zero overhead when off). Turn it on to log per-scene `AvgFPS`, `1%LowFPS`, `P50`/`P95`/`P99`, GC counts, and Unity `ProfilerRecorder` counters (`MainMs`, `RenderMs`, `DrawCalls`, `SetPass`, `Tris`) to `UserData/BeatFramer/perf.log`.

## Building from source

Requires the [.NET SDK](https://dotnet.microsoft.com/) (tested with .NET 8/9/10 SDK on macOS) and a local Beat Saber `1.44.1` installation with `BSIPA`, `SiraUtil`, and `BSML` installed. No NuGet downloads are needed — `.NET Framework 4.7.2` references resolve directly from `Beat Saber_Data/Managed`.

```sh
dotnet build BeatFramer/BeatFramer.csproj -c Release -p:BeatSaberDir="/path/to/Beat Saber"
```

Output: `BeatFramer/bin/Release/net472/BeatFramer.dll`.

To build a release zip (`dist/BeatFramer-v0.1.0.zip`):

```sh
./scripts/package-release.sh "/path/to/Beat Saber"
```

- `BeatFramer/UI/` — BSML Mod Settings panel (`SettingsView.bsml`, host, Zenject installer)
- `dxvk.conf` — optional DXVK config for Proton / Steam Frame / Linux
- `scripts/package-release.sh` — release build & zip script
